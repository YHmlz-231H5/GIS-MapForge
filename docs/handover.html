app-map-downloader

PC 跨平台地图下载器 · 2026-07-21 · Alpha

一句话定位：基于 Electron + React + MapLibre 的桌面端 OSM 地图下载工具——在线搜索区域、下载 PBF，再用 Planetiler 生成本地 PMTiles，供其他应用离线使用。App 本身（底图浏览、区域搜索、PBF 下载）均需联网；支持中国行政区划无 key 搜索。计划作为开源项目发布到 GitHub。

2. 主要功能模块

2.1 区域搜索 & 行政区划

后端用途需要 Key?状态
Photon (Komoot)关键字→ bbox + OSM ID❌ 免费可用
DataV.GeoAtlas (阿里云)adcode → 行政区划边界 GeoJSON❌ 免费可用
Nominatim (OSM)Fallback 地理编码❌ 免费Fallback

流程: 用户输入 "深圳龙华" → Photon 返回 bbox → 启发式 adcode → DataV 返回边界多边形 → MapView 绘制绿色叠加层.

2.2 底图切换

类别默认源说明
矢量 (国际)OpenFreeMap Liberty免费, 无 key
矢量 (中国)高德街道免费, 无 key, 国内速度快
栅格卫星 (国际)ESRI World Imagery免费, 无 key
栅格卫星 (中国)高德卫星免费, 无 key
可选MapTiler Streets需 key (Settings 面板配置)

共 13 种源, 左上角绿色 badge 显示当前源, 启动时 HEAD probe 自动选可用源.

2.3 Layer Curation (6 问选择)

  1. 用途: overview / city / street / route — 决定默认 layer 集
  2. 底图层: 多选 (coastline, water, landuse, park, boundary)
  3. 道路: all / major / no labels
  4. 建筑: all / major / none
  5. 地点标签 + POI: 地点 + POI 开关
  6. 其它: waterway, aeroway, mountain_peak

OpenMapTiles 标准 schema (16 层), 选项存为 LayerSet, 传给 Planetiler.

2.4 任务系统

任务类型说明优先级状态
pbf-download-osm-apiOSM API 88 tile 网格 → merge → .pbfLIGHTWorker crash
planetiler-convertPBF → PMTiles (Java Planetiler)HEAVY未测
pbf-download-geofabrikGeofabrik 区域下载LIGHT未接入 UI
raster-download-xyz栅格 XYZ 瓦片下载LIGHTPhase 2

调度器: 每 1s tick, LIGHT 最多 3 并行, HEAVY 独占. 状态机: queued → running → done/failed/killed/cancelled. 持久化到 SQLite.

2.5 分步工作流 (PBF → PMTiles)

  1. LayerCurationDrawer → "▶ 下载 PBF" → 创建 pbf-download-osm-api 任务
  2. PBF 任务完成后, TaskQueue 显示绿色 "生成PMTiles" 按钮
  3. 点击 → 创建 planetiler-convert 任务

3. 使用流程

3.1 首次启动

# 1. 安装依赖 cd app-map-downloader npm install # 含 postinstall: electron-rebuild # 2. 下载 Planetiler (如未安装) # 从 https://github.com/onthegomap/planetiler/releases 下载 planetiler.jar # 放到 tools/planetiler.jar # 3. 开发模式启动 npm run dev # 自动构建 + 启动 Electron # 4. 无 GPU 模式 (如果 WebGL 失败) npm run dev:no-gpu

3.2 典型操作流程

  1. 左侧面板 → 搜索框输入地名 (如 "深圳龙华") → 回车
  2. Photon 返回结果列表 → 点击选择 (或手动输入 bbox)
  3. DataV 自动加载行政区边界 → 地图显示绿色叠加层
  4. 点击 "下一步: 选择 layers" → LayerCurationDrawer 弹出 (居中, 672px 宽)
  5. 选择用途预设 + 微调 6 类 layer + Planetiler 参数
  6. 点击 "▶ 下载 PBF" → 右侧任务队列出现 queued 任务
  7. 任务完成后, 点击 "生成PMTiles" → Planetiler 开始转换
  8. 生成的 PMTiles 文件下载到本地

6. 已踩过的坑 (Pitfall 精选)

#坑解决
48GPU flag CalculateNativeWinOcclusion 在 Win 11 + Electron 33 上**静默禁用 WebGL**全部删除 disable-features flag, 只保留 background-throttling 三个
52scripts/dev.cjs 硬编码 --disable-gpu → WebGL 永远失败改为 MAP_DISABLE_GPU env var 控制
40Vite 6 的 build.base 被忽略, 必须放顶层 base: './'移到 defineConfig 顶层
56loadFile(__dirname, '../renderer/index.html') 路径错改为 join(__dirname, '..', '..', 'dist', 'index.html')
57CSP script-src 'self' 阻断 inline script内联 script 移到 vendor/suppress-csp-warning.js
50vendor maplibre 5.8 与 Electron 33 WebGL 不兼容回退到 5.7.3, 且必须以 demo vendor 的 hash 为准
65Vite 不自动复制 vendor/ 到 dist/build:renderer 加 post-build node -e 复制脚本
61Scheduler tick 在无 heavy 任务时 skip light 任务同一轮 tick 遍历所有 queued 任务
64spawn(process.execPath) = electron.exe, 不能跑 worker改用 spawn(node, ...) 并设 HERMES_NODE_BIN env var
